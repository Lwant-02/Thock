# Thock

A minimalist mechanical typing playground focused on satisfying keyboard sounds, smooth animations, and a clean typing experience.

## Features

- 30-second typing mode
- Realistic mechanical keyboard sounds
- Animated key press interactions
- Real-time WPM and accuracy tracking
- Random quote fetching
- Minimal dark-themed and light-themed interface
- Smooth and responsive typing experience
- 3D Keyboard

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Web Audio API

## Vision

Thock is designed to make typing feel satisfying.

Instead of focusing on competitive features or complex systems, the goal is to create a polished and immersive typing experience through:

- sound design
- responsive animations
- clean UI
- smooth interactions

## Future Ideas

- Multiple sound packs
- Keyboard visualization
- Theme customization
